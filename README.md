## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|------|---------|
| index.html | หน้าหลัก โดยเนื้อหาแตกต่างกันตาม branch |
| about.html | หน้าประวัติส่วนตัวใน feature/about |
| css/style.css | รูปแบบการแสดงผลใน feature/style |
| js/script.js | สคริปต์สลับธีมและจดจำธีมใน feature/script |

## วิธีเปิดใช้งาน
สลับไปยัง branch ที่ต้องการตรวจสอบ แล้วเปิด index.html ด้วยเว็บเบราว์เซอร์
สำหรับประวัติส่วนตัว ให้เปิด about.html ใน feature/about

แต่ละ branch แยกฝึกตามใบงานและยังไม่ได้รวมคุณสมบัติทั้งหมดเข้าด้วยกัน
CSS อยู่ใน feature/style ส่วน JavaScript อยู่ใน feature/script

## รายการ branch
| branch | หน้าที่ |
|--------|---------|
| main | สายหลัก |
| feature/header | ส่วนหัวของหน้าเว็บ |
| feature/about | หน้าประวัติส่วนตัว |
| feature/style | ไฟล์ CSS และ .gitignore |
| feature/script | สคริปต์สลับธีมมืดสว่าง |
| docs/readme | เอกสารประกอบ |
| experiment/merge-conflict | ทดลองแก้ conflict |
